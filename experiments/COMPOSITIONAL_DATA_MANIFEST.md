## Validation method

Every example is checked before being kept: the target rule's `can_apply` must accept the generated expression, `apply` must produce a result different from the input, and `Verifier::verify_step` (default `Verifier::new()`, symbolic level) must return `Valid`. An example failing any of these is dropped, not corrected. No example is derived from, or checked against, the locked evaluation corpus at `experiments/corpus/problems.jsonl`.
